# volume-render-optimization
Profiling and optimizing a Python-based 3D volume-rendering pipeline

## Collaborators

This project was completed as a group project with
**Theodor Fritsch** and **Linus Rackner** in March 2026.

The work focused on profiling and optimizing a Python-based
3D volume-rendering pipeline, with particular emphasis on
GPU acceleration using CuPy.

The original volume-rendering implementation was created by
[Philip Mocz](https://github.com/pmocz/volumerender-python).
